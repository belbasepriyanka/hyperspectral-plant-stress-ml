# Hyperspectral demo data

The committed `sample_hyperspectral_disease_preview.csv` is a small public preview. Running `python scripts/run_demo.py` generates the full 360-scan synthetic dataset as `sample_hyperspectral_disease_demo.csv`.

Reflectance curves are programmatically generated across 400–1000 nm for five demonstration classes. Class names are inspired by plant-health research contexts, but values and model results are not measured biological findings.
